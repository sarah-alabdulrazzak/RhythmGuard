# RhythmGuard
A machine learning algorithm for a real-time system to classify ECG and PPG waveforms arrhythmia types based on a few seconds of data. Check out our [demo video](https://www.macvideo.ca/media/Rhythm+Guard+-+Computing+and+Software/1_rz2r6ijf) for the Biomedical Engineering and Mechatronics Capstone course at McMaster University. The [Charlton et al. MIMIC PERform AF dataset](https://zenodo.org/records/6973963) and the [Clifford et al. Computing in Cardiology Challenge 2015 dataset](https://physionet.org/content/challenge-2015/1.0.0/) were used for training the models. Logistic Regression, Decision Tree, and Random Forest models were tested using combined ECG and PPG features, and standardization was performed to eliminate differences between datasets. [The Combined_Models.ipynb](https://github.com/sarah-alabdulrazzak/RhythmGuard/blob/main/Combined_Models.ipynb) file contains the final performance statistics of the ML models.
